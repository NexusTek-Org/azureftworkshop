# 🚀 Azure Frontier Transformation Workshop

This repository supports the **Azure Frontier Transformation Workshop**. It holds the **hands-on labs** — written so you can work through them at your own pace, on your own subscription, without an instructor.

The conceptual sessions are delivered live. Everything here is the part you build with your hands.

---

## 🧭 What's in here

| | |
|---|---|
| **[Session 1 — Building the Foundation](./Session%201%20-%20Building%20the%20Foundation/README.md)** | Build a grounded agent on Microsoft Foundry, then secure, evaluate and monitor it. Two labs, nine exercises. |

Each session folder is self-contained — its own prerequisites, lab data and screenshots — so sessions can be run independently and in any order.

---

## 🏁 Getting started

1. Open the session you are attending.
2. Complete its **Prerequisites** page first. Some items need **24–48 hours** of lead time and cannot be fixed on the day.
3. Work through the labs in order.
